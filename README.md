# Projeto de Sistema de Leilão

Este projeto consiste em um sistema informatizado para rotinas de uma casa de leilões, desenvolvido como parte da Atividade 1 da disciplina de Gerenciamento de Configuração.

## Tecnologias Utilizadas
- **Java**: Linguagem de programação principal para a lógica do sistema.
- - **MySQL**: Sistema de Gerenciamento de Banco de Dados (SGBD) utilizado para persistência de dados.
  - - **Git/GitHub**: Ferramentas utilizadas para o versionamento e hospedagem do código fonte.
   
    - ## Como utilizar
    - 1. Importe o arquivo `sql/database.sql` no seu SGBD MySQL.
      2. 2. Compile e execute os arquivos Java localizados em `src/main/java/com/leilao`.
